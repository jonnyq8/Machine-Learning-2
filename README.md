# Machine Learning II

Coursework and guided labs for **CSCI 4052U – Machine Learning II** at Ontario Tech University. The repository is organized as Jupyter notebooks; it does not contain a standalone application.

## Notebooks

| Notebook | Description |
|---|---|
| [Jonathan_Forrester_MLPClassifier_(worksheet).ipynb](./Jonathan_Forrester_MLPClassifier_(worksheet).ipynb) | Assignment 1 worksheet: build a multilayer perceptron (MLP) to classify Fashion-MNIST images. |
| [Jonathan_Forrester_ConvNet_(worksheet).ipynb](./Jonathan_Forrester_ConvNet_(worksheet).ipynb) | Assignment 1 worksheet: build a convolutional neural network (ConvNet) for Fashion-MNIST classification. |
| [Jonathan_Forrester_ResNetClassifier_(worksheet).ipynb](./Jonathan_Forrester_ResNetClassifier_(worksheet).ipynb) | Assignment 1 worksheet: build a ResNet-based image classifier. |
| [Jonathan Forrester's lab3.ipynb](./Jonathan%20Forrester%27s%20lab3.ipynb) | Lab 3: run a pretrained single-shot object detector and examine its detections, localization, classification, confidence thresholds, and performance on small objects. |
| [Jonathan_Forrester's_assignment2.ipynb](./Jonathan_Forrester%27s_assignment2.ipynb) | Assignment 2: fine-tune YOLOv3 on the African Wildlife dataset and evaluate the results. |

## Getting started

1. Open a notebook in [Google Colab](https://colab.research.google.com/) or a local Jupyter environment.
2. Follow the setup instructions in that notebook, then run its cells from top to bottom.
3. Complete the cells and written responses marked for you in the assignment or lab.
4. Save the completed notebook with its outputs if you need to submit or review your work.

The notebooks may install or download their own dependencies and datasets as part of their setup. For Assignment 2, use a GPU runtime; training is substantially slower without one. Check each notebook for its specific environment and submission instructions.
